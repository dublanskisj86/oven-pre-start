Granola Oven Speed Guide

Quick daily reference for tunnel belt and hopper spreader speed changes.

Start slow
increase gradually Helps control finished granola moisture
Why the slow start matters Starting too fast can leave granola too high in moisture. Begin slowly so the product has enough time in the oven.
Hopper spreader Drops granola onto the oven belt. Keep both sides matched to the speed shown in the guide.

Daily checks to remember

  • Pre-heat the oven before production setup begins.
  • Start Transport, Cooling, and Heating.
  • Wait until B3 / Burner 3 Actual Power is under 50% before starting production.
  • Start with the Gentle Start setting: 12 Hz belt and 4.2 Hz / 4.2 Hz hopper spreader.
  • When granola reaches the kibbler, follow the 10-minute ramp-up sequence.
  • Keep the oven temperature at or below 150 C.
