Tunnel belt delay

If any interval on the tunnel belt exceeds 5 minutes, revert to the Granola Transition Phase settings.

Maximum oven temperature at any time:

150 C

Daily checks to remember

  • Pre-heat the oven before production setup begins.
  • Start Transport, Cooling, and Heating.
  • Wait until B3 / Burner 3 Actual Power is under 50% before starting production.
  • Confirm the tunnel belt speed matches the current phase.
  • Confirm both hopper spreaders are set to the matching speed.
  • Keep the oven temperature at or below 150 C.
